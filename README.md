# BAKE-NAVIGATOR

Собственный GPS-навигатор для Казахстана на базе OpenStreetMap.

## Текущий этап: первый прототип

Сейчас в проекте готовится первая версия приложения:

- карта OpenStreetMap с центром на Шымкенте;
- получение текущего местоположения через GPS при разрешении пользователя;
- непрерывное обновление GPS-маркера при движении;
- фоновая GPS-навигация на Android: при нажатии «Старт» включается системное постоянное уведомление и GPS продолжает обновляться при свёрнутом приложении или выключенном экране;
- отображение оценки точности GPS;
- проверка отклонения от линии маршрута и автоматический запрос нового маршрута после нескольких качественных GPS-замеров;
- отдельный экран настроек разрешений Android: геолокация, микрофон, уведомления, физическая активность, камера, контакты, телефон, Bluetooth-устройства поблизости, фото и видео;
- локальный профиль автомобиля (марка, модель, цвет, номер), сохраняемый на устройстве;
- импорт MBTiles-файла, локальная проверка архива и переключение между онлайн-картой и офлайн-картой;
- поиск адреса по Казахстану вручную через Nominatim (по кнопке, без автоподсказок);
- выбор пункта назначения долгим нажатием на карту;
- тестовое построение автомобильного маршрута через OSRM с получением дорожных манёвров;
- запуск и остановка режима навигации;
- голосовые подсказки о следующем манёвре и дороге через установленный на Android движок TTS;
- переход к следующей подсказке при приближении GPS-позиции к точке манёвра.

### Фоновая навигация Android

При нажатии «Старт» в открытом приложении GPS-поток переключается на Android location foreground service с постоянным уведомлением. Это позволяет продолжать получать координаты, пока приложение свёрнуто или экран выключен. При остановке навигации, прибытии или очистке маршрута постоянный режим GPS отключается.

Сервис запускается только после явного нажатия пользователя в открытом приложении. Это не гарантирует работу после принудительной остановки/смахивания приложения из списка последних, выключения телефона или ограничений энергосбережения производителя. Для реальной эксплуатации нужно отдельно испытать поведение на конкретных моделях Samsung и настроить исключения энергосбережения, если Android их применяет. Голосовые подсказки в фоне также требуют проверки на устройстве.

Это начальный прототип, а не готовый навигатор уровня Яндекс Навигатора. Перерасчёт при отклонении использует расстояние до линии маршрута и несколько качественных GPS-замеров; полноценное map-matching ещё требует тестов. Поиск номера дома возможен, если адрес есть в OSM; подъезды находятся только при наличии отмеченного входа. Приложение поддерживает импорт MBTiles для офлайн-отображения карты, но готовый пакет Шымкента ещё нужно подготовить и проверить.

## Технологии

- Flutter / Dart — Android-приложение.
- OpenStreetMap — открытые картографические данные.
- flutter_map — отображение карты.
- Geolocator — GPS телефона.
- OSRM — тестовое построение маршрутов.
- Flutter TTS — голосовое озвучивание.

## Важные ограничения прототипа

- Поиск адресов обращается к публичному Nominatim только после нажатия кнопки. Публичный сервис имеет строгие ограничения частоты запросов и не предназначен для массового коммерческого использования; при росте проекта понадобится собственный поиск или отдельный поставщик.
- Используется публичный демонстрационный сервер OSRM. Он предназначен для тестирования, а не для постоянной коммерческой нагрузки. Перед реальным запуском нужно развернуть собственный сервер маршрутизации или выбрать подходящего поставщика.
- Используются стандартные публичные тайлы OpenStreetMap для онлайн-карты. Их нельзя массово скачивать с tile.openstreetmap.org для подготовки офлайн-карт.
- Импортированная MBTiles-карта отображается без интернета. Построение маршрута через публичный OSRM и поиск адресов через Nominatim по-прежнему требуют интернет; офлайн-маршрутизация и офлайн-поиск пока не реализованы.
- Для автономной работы нужен отдельно подготовленный MBTiles-пакет из источника, разрешающего офлайн-использование, с соблюдением лицензии ODbL.
- Наличие адресов, подъездов, ограничений и дорожных событий зависит от полноты исходных картографических данных. Их качество нужно проверять на реальных поездках.

## Сборка Android

В GitHub Actions добавлен ручной workflow **Build BAKE Navigator APK**. Он запускается только вручную через вкладку Actions и не стартует автоматически при каждом изменении кода.
