# BAKE Navigator — автоматическая диагностика

## Как работает

1. Приложение записывает необработанные Flutter- и платформенные ошибки.
2. GPS-диагностика отправляет только аномалии: задержки callback/fix, скачки расстояния, плохую точность и ошибки GPS-потока.
3. Если интернета нет, до 100 отчётов остаются в локальной очереди телефона.
4. При подключении к Supabase очередь отправляется автоматически; повторная отправка продолжается при следующем запуске и примерно каждые 45 секунд, пока приложение открыто.
5. Отчёты доступны ChatGPT через подключённое соединение Supabase и могут быть разобраны в чате. Отдельный OpenAI API не нужен.

## Что отправляется

- категория ошибки, время, версия приложения и платформа;
- тип исключения и стек вызовов;
- технические метрики GPS без координат.

Сырые координаты, адреса, точки назначения, поисковые запросы и идентификатор устройства не отправляются. URL в тексте ошибки удаляются; координатные пары маскируются.

## Доступ и безопасность

- Клиенту разрешена только вставка строк в `app_error_reports`.
- Публичное чтение, изменение и удаление таблицы запрещены RLS и GRANT.
- Отчёты читаются через подключённый Supabase project tooling.
- Публичный publishable key используется так же, как для существующей синхронизации дорожных отметок; Secret/service_role key в APK не добавляется.

## Ограничение GitHub Issues

Приложение не содержит GitHub Personal Access Token. Поэтому оно не создаёт Issues напрямую. ChatGPT может прочитать отчёты из Supabase и после анализа создать Issue через подключённое GitHub-соединение. Автоматическая фоновая публикация Issues потребовала бы отдельного защищённого серверного GitHub-токена; он не должен попадать в APK. Сборка APK и автоматический запуск сборок этой настройкой не включаются.
