# BAKE Navigator — автоматическая диагностика

## Поток отчётов

1. Приложение записывает необработанные Flutter- и платформенные ошибки.
2. GPS-диагностика отправляет только аномалии: задержки callback/fix, скачки расстояния, плохую точность и ошибки GPS-потока.
3. Если интернета нет, до 100 отчётов остаются в локальной очереди телефона.
4. При доступном интернете приложение отправляет отчёты напрямую в таблицу Supabase `app_error_reports`.
5. После успешной вставки отчёт удаляется из локальной очереди. Если запись с таким ID уже существует (повтор после сетевого сбоя), локальный дубль также удаляется.
6. ChatGPT может прочитать записи из Supabase по запросу пользователя и разобрать причину ошибки. Автоматического фонового наблюдения и автоматического создания GitHub Issues нет.

## Данные

- категория, время, версия приложения и платформа;
- тип ошибки и стек вызовов;
- технические метрики GPS без координат.

Координаты и адреса маскируются на устройстве. Из details удаляются поля с названиями lat/lon/coord/address/route/query/destination. Сырые координаты не отправляются.

## Настройка

- Нужны только существующие `SUPABASE_URL` и publishable/anon key, уже используемые приложением.
- Новый GitHub-токен, GitHub-регистрация, OpenAI API и платные API не нужны.
- RLS таблицы `app_error_reports` остаётся включённым; клиенту разрешена только вставка.
- Публичное чтение, изменение и удаление диагностических записей запрещены.

## Проверка

После следующей сборки APK нужно отправить тестовую ошибку и убедиться, что:
1. строка появилась в `app_error_reports`;
2. локальная очередь очистилась после успешной вставки.

APK, Flutter analyze и runtime-тест пока не запускались.
