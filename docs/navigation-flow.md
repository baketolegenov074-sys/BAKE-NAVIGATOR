# BAKE Navigator — схема переходов по 18 референсным экранам

Источник: 18 изображений в ветке `navigator-search-ui-fix` (11 первоначальных + 7 дополнительных). Внешний вид BAKE остаётся собственным; фотографии используются как карта структуры, действий и переходов.

## Главный экран карты

- Карта — основной фон на всю доступную область.
- Верхняя строка: профиль, поиск, меню маршрута.
- На карте: парковка, масштаб +/- и возврат к GPS.
- Нижняя панель компактная, только иконки: Поиск, Маршрут, АЗС, Закладки, Настройки.
- Удалена дополнительная строка фильтров «Сети / Оплата из машины»; она была лишней и не должна закрывать карту.
- Долгое нажатие по карте открывает контекст выбранной точки.

## Переходы по функциям

| Откуда нажали | Что открывается | Дальнейшие действия |
|---|---|---|
| Верхняя кнопка профиля | Профиль и главное меню | Загрузка карт, поддержка, слои, размещение объекта, геопозиция, закладки, заправки, парковки, настройки, история/отзывы/BAKE Plus |
| Поле/иконка поиска | Поиск | Вкладки «Категории» и «История», строка текстового поиска |
| Категория «АЗС» | Сети АЗС | Газпромнефть Казахстан, Sinooil, Qazaq Oil, Gasenergy, Helios, TS и другие; выбор сети запускает поиск |
| Другие категории поиска | Результаты поиска | Где поесть, продукты, аптеки, банкоматы, отели, автомойки, автосервисы, больницы, кинотеатры, бары/пабы, магазины |
| Нижняя кнопка «Маршрут» / меню маршрута | Меню маршрута | Планирование, изменить маршрут, добавить точку, варианты, параметры, поделиться, сообщить об ошибке |
| «Планирование маршрута» | Экран маршрута | Откуда, Куда, промежуточные остановки, дата и время выезда |
| «Время выезда» | Отдельная панель времени отправления | Дата, время, «Готово», «Сбросить» |
| После расчёта маршрута | Варианты маршрута | Время и километраж альтернатив, выбор варианта, «Поехали» |
| Долгое нажатие на карту | Точка на карте | Координаты, копирование, «Что здесь», сообщить об объекте, дорожное событие, поделиться, «Отсюда», «Сюда», остановка, закладка |
| «Изменить карту и слои» | Панель слоёв | Схема доступна; закладки и парковки открывают соответствующие функции; спутник/гибрид, пробки и панорамы пока не подключены |
| «Настройки» | Меню разделов настроек | Звук, параметры маршрута, внешний вид/слои, офлайн-карты и автомобиль |
| «Загрузка карт» | Экран управления офлайн-картой | Импорт MBTiles, включение/отключение офлайн-карты |
| Музыкальная панель (фото 18) | Отдельная внешняя интеграция | Не имитировать плеер: музыкальный провайдер BAKE ещё не выбран и интеграция не подключена |

## Что уже связано в коде рабочей ветки

- Главная карта больше не содержит большую карточку «Готов к поиску маршрута»; нижняя панель сведена к компактным иконкам.
- Удалена дополнительная панель «Сети / Оплата из машины».
- Поиск открывает отдельную панель с категориями и историей. История сохраняется локально (до 20 запросов).
- АЗС открывает список сетей, а не сразу ищет одну выбранную сеть.
- Профильное меню разделено на реальные действия и честные сообщения для ещё не подключённых серверных сервисов.
- Панель слоёв отделена от общей страницы настроек. Неподключённые слои отключены, чтобы не изображать работающий спутник/трафик/панорамы.
- Настройки теперь открывают отдельные панели звука, параметров маршрута и слоёв; офлайн-карта и автомобиль остаются на существующем экране настроек.
- Меню маршрута открывает планировщик, варианты маршрута, отдельную панель параметров, копирование маршрута и форму отчёта (копирование отчёта, не отправка на сервер).
- Время отправления вынесено в отдельную панель с датой, временем, «Готово» и «Сбросить».
- В списке вариантов есть действие «Поехали».
- Точка карты поддерживает обратное геокодирование OSM, копирование координат, действия «Отсюда», «Сюда», остановку, закладку, ссылку и локально сформированный отчёт.

## Что пока не является полноценной серверной функцией

- Поддержка, размещение нового объекта и дорожное событие: формы/отчёты пока копируются на устройство; серверная отправка и модерация не подключены.
- Пробки, панорамы, спутниковая/гибридная карта: нет поставщика соответствующих данных/тайлов.
- Бронирования, история заказов, отзывы и BAKE Plus: собственного сервиса ещё нет; эти пункты показывают объяснение, а не фальшивый экран.
- Музыка: нет выбранного музыкального API или разрешённой интеграции воспроизведения.
- Избегание платных/грунтовых дорог сохраняется в настройках, но тестовый профиль OSRM пока не применяет эти параметры.
- Офлайн-режим принимает готовый MBTiles. OSM PBF не подключается напрямую как тайловая карта.

## Проверка

Изменения сохранены только в ветке `navigator-ui-work`. APK не собирался, анализ Flutter и проверка на телефоне не запускались. Для следующего этапа нужно отдельно разрешить запуск GitHub Actions; после сборки проверить каждый переход на Samsung Android, GPS, поиск и реальную работу MBTiles.
