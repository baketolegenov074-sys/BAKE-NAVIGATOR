# Подключение общей базы дорожных отметок BAKE

Код сервера хранится в этом репозитории, но сама база работает в Supabase Free.

## 1. Создать бесплатный проект

1. Открыть https://supabase.com/dashboard и войти через свой аккаунт.
2. Создать организацию и проект на плане Free.
3. Сохранить пароль базы данных в надёжном месте.

Free-проект включает PostgreSQL, API и Realtime. При низкой активности проект может автоматически приостановиться после недели.

## 2. Создать таблицы и правила доступа

1. Открыть проект -> SQL Editor -> New query.
2. Скопировать весь файл `supabase/road_reports.sql` из репозитория.
3. Нажать Run.
4. В Authentication -> Sign In / Providers включить Anonymous Sign-Ins.

Публичный ключ приложения не даёт права подтверждать отметки: права ограничены RLS-политиками. Только пользователи, внесённые в `public.road_admins`, могут менять статусы.

## 3. Добавить владельца-администратора

1. В Authentication -> Users создать пользователя с email и паролем владельца.
2. Скопировать его User UID.
3. В SQL Editor выполнить запрос, заменив UUID на скопированный UID:

```sql
insert into public.road_admins (user_id)
values ('ВСТАВЬТЕ-USER-UID')
on conflict (user_id) do nothing;
```

Не добавлять в эту таблицу обычных пользователей.

## 4. Подключить проект к сборке GitHub

В Supabase открыть Project Settings -> API. Нужны:
- Project URL;
- publishable key (или legacy anon key). Никогда не использовать service_role/secret key в приложении.

В GitHub открыть Settings -> Secrets and variables -> Actions -> New repository secret и создать:
- `SUPABASE_URL` — Project URL;
- `SUPABASE_ANON_KEY` — publishable/anon key.

Workflow `.github/workflows/build-android.yml` уже передаёт эти значения в Flutter через `--dart-define`. Сборку он сам не запускает.

## Как будет работать приложение

- Телефон отправляет отметку в общую таблицу со статусом «На проверке».
- Администратор входит по email и паролю в «Кабинет администратора».
- После подтверждения отметка появляется на картах всех подключённых телефонов через Realtime.
- Если интернет недоступен, отметка остаётся локально и повторно отправляется при следующем запуске приложения.
- Новые отметки и изменения статусов не требуют нового APK. Для уже установленных старых версий сетевой код появится только после одного обновления APK.

## Ограничения бесплатного плана

Supabase Free: 500 MB базы на проект, 5 GB исходящего трафика, 50 000 активных пользователей в месяц, 2 млн Realtime-сообщений в месяц. Проект может приостановиться после недели недостаточной активности. Для постоянно критичного сервиса бесплатный план не гарантирует бесперебойную работу.
