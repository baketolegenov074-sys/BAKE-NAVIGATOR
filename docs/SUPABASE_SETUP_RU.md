# BAKE Navigator — подключение общей базы дорожных отметок

## Что используется в приложении

- Обычные пользователи не регистрируются и не входят в аккаунт.
- Приложение обращается к Supabase через Project URL и Publishable key.
- Случайный постоянный `device_id` создаётся один раз и хранится в SharedPreferences телефона.
- Каждая отметка сначала сохраняется локально. При наличии интернета она отправляется в `road_reports`.
- Неотправленные отметки повторно отправляются при следующем запуске приложения.
- Общая карта загружает только отметки со статусом `Подтверждено`.
- Realtime подписка обновляет список подтверждённых отметок.

## Параметры сборки

GitHub Actions использует secrets:
- `SUPABASE_URL` — Project URL.
- `SUPABASE_ANON_KEY` — значение Publishable key проекта (несмотря на историческое имя секрета).

Не добавляйте в приложение `service_role` или Secret key.

## SQL

Файл `supabase/road_reports.sql` настраивает RLS и публичный доступ только на чтение и добавление отметок:
- чтение разрешено без входа;
- добавление разрешено без входа, только со статусом `На проверке`;
- публичное изменение и удаление запрещено.

При первом подключении или после обновления схемы весь SQL-файл нужно выполнить в SQL Editor Supabase.

## Ограничение безопасности

Publishable key не является паролем и может находиться в приложении. Поэтому публичные вставки можно спамить, а `device_id` — это метка устройства, не доказательство личности. Публичный клиент не получает права подтверждать или отклонять точки. Для безопасной модерации потребуется отдельный защищённый канал администратора; email/пароль обычных пользователей не нужны.
